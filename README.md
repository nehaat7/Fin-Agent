# FinAgent: an agentic financial-data assistant on AWS serverless with MCP

Ask questions like *"Compare NVDA and AMD over the last year"*. Claude decides which tools to call, an MCP server running on Lambda fetches live market data, and Claude writes up the answer.

## Architecture

```
Browser ──HTTPS──▶ Agent Lambda (Function URL)
                    │  GET  /      → chat UI (index.html)
                    │  POST /chat  → agent loop
                    │
                    ├──▶ Amazon Bedrock: Claude Opus 4.6 (us.anthropic.claude-opus-4-6-v1), Messages API, tool use
                    │
                    └──MCP (Streamable HTTP, JSON-RPC, Bearer token)──▶ MCP Server Lambda (Function URL)
                                                                        └──▶ Yahoo Finance (yfinance)
```

| Component | Tech | Notes |
|---|---|---|
| `mcp_server/` | Python 3.13 Lambda | Stateless MCP server (protocol 2025-11-25, also 2025-06-18/03-26) over Streamable HTTP with JSON responses. Handles `initialize`, `tools/list`, `tools/call`, `ping`. Shared-secret bearer auth. |
| `agent/` | Python 3.13 Lambda, `anthropic[bedrock]`, `mcp` 2.x client | Discovers tools from the MCP server at runtime, then runs a Claude tool-use loop (parallel tool calls, max 10 turns). Returns the answer plus a tool-call trace. |
| `template.yaml` | AWS SAM | Two functions, Function URLs, IAM (`bedrock-mantle:CreateInference`), X-Ray tracing. |

### MCP tools
| Tool | What it returns |
|---|---|
| `get_quote` | Price, change, market cap, P/E, P/B, 52-week range, beta, analyst target |
| `get_price_history` | Sampled closes plus total return, annualised volatility, max drawdown |
| `get_company_profile` | Sector, industry, employees, business summary |
| `get_financial_statements` | Key income/balance/cash-flow lines, latest 4 annual or quarterly periods |
| `get_news` | Recent headlines |
| `search_ticker` | Company name → ticker symbol |

The agent never hard-codes these tools. It calls `tools/list` on the MCP server each time, so adding a tool to `mcp_server/tools.py` makes it available to Claude with no agent changes.

## Deploy

Prerequisites: an AWS account (us-east-1) with the Anthropic use-case form submitted in the Bedrock console, and Python 3.13.

```bash
python3 -m venv .venv && .venv/bin/pip install awscli aws-sam-cli "mcp==2.3.0" "anthropic[bedrock]" yfinance
aws login --region us-east-1 --profile fin-agent   # AWS CLI v2 browser sign-in
AWS_PROFILE=fin-agent ./deploy.sh   # builds Linux bundles (no Docker), deploys the stack, prints ChatUrl
```

Open the printed `ChatUrl` in a browser.

To use a different model: `MODEL_ID=<id> AWS_PROFILE=fin-agent ./deploy.sh`. IDs starting with `us.`/`global.` go through
Bedrock inference profiles. IDs starting with `anthropic.` (for example `anthropic.claude-opus-5-5`) use Bedrock's
Messages-API endpoint. Check that your project has a non-zero quota for the model under Service Quotas → Amazon Bedrock.
New projects start with 0 for the newest models and about 5 requests/min for Opus 4.6, and the agent retries on throttling.

## Test

```bash
# MCP server locally + the official MCP client
MCP_AUTH_TOKEN=localtest .venv/bin/python scripts/local_mcp_server.py &
.venv/bin/python scripts/test_mcp_client.py http://127.0.0.1:8765/mcp localtest

# Deployed MCP server
.venv/bin/python scripts/test_mcp_client.py "<McpServerUrl>" "$(cat .mcp_token)"

# Deployed agent
curl -s -X POST "<ChatUrl>chat" -H 'content-type: application/json' \
  -d '{"messages":[{"role":"user","content":"What is AAPL trading at?"}]}'
```

The deployed MCP endpoint also works from any MCP client (Claude Desktop, Claude Code, MCP Inspector) with the header `Authorization: Bearer <token>`.

## Design notes and limitations

- **Stateless MCP on Lambda:** each JSON-RPC POST gets one JSON response, and there's no session or SSE stream. GET returns 405, which the spec allows. This matches Lambda's request/response model and scales horizontally.
- **Security:** the MCP server needs a bearer token (generated by `deploy.sh` and stored in `.mcp_token`). The chat URL is public so it's easy to demo. Before real use, put it behind Cognito/IAM auth or API Gateway with throttling, and move the token to Secrets Manager.
- **Data source:** Yahoo Finance is unofficial and sometimes rate-limits cloud IPs. Tool errors go back to Claude (`isError: true`), and it explains them to the user. For production, swap in a licensed data API inside `tools.py`.
- **Conversation state** lives in the browser: the full text history is sent on each request.
- **Model choice:** Opus 4.6 is the newest Claude model with quota on this project. Claude Opus 5.5 needs its Bedrock quota raised first.
- Not investment advice.
